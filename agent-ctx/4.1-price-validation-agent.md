# Task 4.1 — Server-Side Order Price Validation

## Agent: price-validation-agent
## Date: 2026-03-05

## Summary
Added server-side order price verification and restaurant hours check to the orders POST handler to prevent malicious clients from submitting modified totals and to block orders when the restaurant is closed.

## Files Modified

### 1. `src/lib/constants.ts`
- Added `RESTO_HOURS` constant: `{ open: 11, close: 23, timezone: 'Africa/Conakry' }`
- Added `isRestaurantOpen()` function: compares UTC hours against open/close (Conakry is GMT)

### 2. `src/app/api/orders/route.ts`
- Added import: `import { isRestaurantOpen } from "@/lib/constants"`
- **Restaurant hours check** (line 81-84): Rejects `dine_in` and `takeaway` orders when `!isRestaurantOpen()`, returns 400 with French message
- **Server-side price verification** (lines 89-115):
  - Parses `items` JSON from request body
  - Fetches all available menu items from DB via `db.menuItem.findMany({ where: { available: true } })`
  - For each ordered item, looks up matching DB item by name and replaces client price with DB price
  - Recalculates total as `sum(dbItem.price * qty) + deliveryFee - discount`
  - Uses `verifiedItems` (stringified) and `verifiedTotal` in `db.order.create()`
