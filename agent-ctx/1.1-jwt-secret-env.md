# Task 1.1 — Move JWT_SECRET to Environment Variables

**Status**: Completed

## Changes Made

### 1. `/home/z/my-project/.env`
Added `JWT_SECRET` with a cryptographically secure 64-character hex string:
```
JWT_SECRET=JWT_SECRET_REDACTED
```
Existing `DATABASE_URL` line was preserved.

### 2. `/home/z/my-project/src/lib/auth.ts`
- **Removed**: Hardcoded fallback `|| 'kfm-delice-secret-key-change-in-production'`
- **Before**: `const JWT_SECRET = process.env.JWT_SECRET || 'kfm-delice-secret-key-change-in-production';`
- **After**:
  ```ts
  const JWT_SECRET = process.env.JWT_SECRET;
  if (!JWT_SECRET) throw new Error('JWT_SECRET environment variable is required');
  ```

This ensures the application fails fast at startup if `JWT_SECRET` is not configured in the environment, eliminating the risk of running with a weak/default secret.
