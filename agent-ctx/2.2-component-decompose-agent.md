## Key Design Decisions
1. **Utility imports stay in tab components**: All tab components already had direct imports from `@/lib/constants` for utilities like `formatPrice`, `statusColors`, `statusLabels`, etc. The `undefined as any` hacks were only in AdminDashboard's prop passing, not in the actual component usage.
2. **`apiPost` removed from tab interfaces**: While not strictly a "utility from constants", `apiPost` was being passed to 8 tab components that never destructured or used it. Removing it cleans up the interface contracts.
3. **`apiPost` kept in AdminDashboard**: The `apiPost` function is still defined and used in AdminDashboard's own CRUD helpers (saveMenu, saveDriver, etc.), so it remains in the parent component.
4. **No functional changes**: All existing functionality is preserved - the utility functions are simply sourced from imports rather than props.
